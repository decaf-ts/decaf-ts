# DECAF-40 — BI Dashboard Embed Plugins (Kibana & Superset)

**Status:** Completed
**Priority:** High
**Owner:** AI Agent

## 1. Overview

Add two new dedicated plugin subtrees under `@decaf-ts/integrations`:

- `integrations/src/plugins/kibana` — **installer source code** (TypeScript that generates/materializes the plugin)
- `integrations/src/plugins/superset` — **installer source code** (TypeScript patch/build scripts)

The `install()` method writes its **output** to a separate directory at the package root (NOT inside `src/`):

- `integrations/plugins/kibana/` — materialized Kibana plugin source (generated by `install()`)
- `integrations/plugins/superset/` — materialized Superset patch/build scripts (generated by `install()`)

These output directories are `.gitignore`-managed: only hand-curated configuration files (`.gitignore`, `README.md`, Dockerfiles, `docker-compose.yml`, host pages) are tracked; all generated plugin source, build artifacts, zips, and `node_modules` are ignored (see §4.6).

Each subtree ships a **multi-tenant dashboard embed plugin** plus a host-side helper API. The Kibana plugin is the reference implementation and follows the [Kibana plugin generator](https://github.com/elastic/kibana/tree/main/packages/kbn-plugin-generator) conventions. The Superset plugin is scaffolded to the **exact same API** but its BI-specific internals are intentionally left as stubs for now ("to be ignored for now"); only the shared contract, install surface, and host helpers are implemented and tested.

### Core design constraint

The plugin is **org-agnostic**. There is **never space switching** inside the plugin. Each org already lands in its own Kibana space through the backend proxy/session URL, so the same plugin serves every org and each org can switch only among dashboard IDs visible in its own space. The plugin only switches dashboards within the current space.

The embed is a **single stable iframe**: org/space/dashboard are supplied at runtime (via URL params and `postMessage`), with validation hooks and message-based dashboard switching.

### Why this lives in `integrations`

The iframe plugin itself runs **inside** the BI tool (browser + React + `@kbn/*` for Kibana). It cannot be a runtime dependency of the Node `integrations` package. The `integrations` package role is therefore:

1. Define the **shared message protocol & contract** used by both the host app (Angular) and the embedded plugin — kept version-stable and DOM-free so it is consumable from Node and the browser.
2. Provide an **installer** that materializes the plugin source files into a target BI plugin directory, parameterized by BI tool version. For Kibana the plugin must be built within the Kibana repo against the exact Kibana version, so `install` writes the source and optionally invokes the build.
3. Provide **host-side helpers**: an embed-URL builder and a DOM-free `postMessage` switch-dashboard helper for the Angular host.

## 3. User Stories / Requirements

*   **US-1:** As an Angular host developer, I want a single stable iframe URL per org and a `postMessage` helper to switch dashboards so I can embed BI dashboards without reloading the iframe.
*   **US-2:** As a platform engineer, I want to install the Kibana embed plugin into a target Kibana instance by writing the generated source (and optionally building it) so the same org-agnostic plugin serves every org.
*   **US-3:** As a maintainer, I want the Kibana and Superset plugins to expose the identical API so the host app is BI-tool agnostic.
*   **Req-1:** The plugin must be org-agnostic; no space switching occurs inside the plugin. The current space comes from the request/session/proxy context.
*   **Req-2:** Dashboard switching must happen via `postMessage` (`ORG_DASHBOARD_EMBED_SWITCH_DASHBOARD`) with optional `timeRange`, `query`, and `filters`.
*   **Req-3:** The plugin must emit lifecycle messages to the parent: `READY`, `RENDERED`, `ERROR`.
*   **Req-4:** Parent origins must be validated against an allowlist (URL param `parentOrigin`, defaulting to the iframe origin).
*   **Req-5:** Both plugins MUST expose the exact same API (same interface, same option/result shapes, using a generic `targetVersion` field instead of tool-specific version keys).
*   **Req-6:** The integrations package source must remain DOM-free (no `window`/`HTMLIFrameElement` types) so it builds under the Node `lib: ["es2022"]` tsconfig.
*   **Req-7:** Kibana plugins must match the exact Kibana version; the installer must accept a `targetVersion` and bake it into `kibana.json`.
*   **Req-8:** Runtime code must throw only Decaf error types (`InternalError`, `UnsupportedError`, etc.).

## 4. Architecture & Design

### 4.1 Folder layout

**Installer source** (tracked in git, compiled by the package build):

```
integrations/src/plugins/
  index.ts              // aggregator: re-exports kibana + superset + shared contract
  contract.ts           // shared, DOM-free contract (types, message protocol, interfaces)
  kibana/
    index.ts            // named exports: KibanaDashboardEmbedPlugin, kibanaDashboardEmbedPlugin, ...
    types.ts            // kibana-specific types (re-exports/shared)
    manifest.ts         // builds kibana.json manifest for a target version
    templates.ts        // generated plugin source as version-parameterized string templates
    installer.ts        // KibanaDashboardEmbedPlugin class (buildEmbedUrl, createSwitchDashboardMessage, sendSwitchDashboardMessage, install, manifest)
    host.ts             // buildKibanaEmbedUrl + sendSwitchDashboardMessage convenience exports
  superset/
    index.ts
    types.ts
    manifest.ts
    templates.ts        // patch scripts + build scripts as string templates (materialized by installer)
    installer.ts        // SupersetDashboardEmbedPlugin class (same API; install = clone+patch+build)
    host.ts             // buildSupersetEmbedUrl + sendSupersetSwitchDashboardMessage
```

**Install output** (generated by `install()`, `.gitignore`-managed — see §4.6):

```
integrations/plugins/
  kibana/               // install() writes generated plugin source here
    .gitignore           // tracked — ignores everything except curated config
    org_dashboard_embed/ // ← generated, gitignored
      kibana.json
      public/
      server/
      ...
  superset/             // install() writes patch/build scripts here
    .gitignore           // tracked — ignores everything except curated config
    org_dashboard_embed_superset/  // ← generated, gitignored
      patches/
      build/
      README.md
      .superset-source/  // ← cloned Superset source, gitignored
```

The `install()` `targetPath` should point to `integrations/plugins/kibana` or `integrations/plugins/superset` respectively. The installer creates a subdirectory (`org_dashboard_embed` / `org_dashboard_embed_superset`) inside `targetPath` for the generated files.

**Key difference in how each plugin is built:**

- **Kibana:** Decaf holds the *generated plugin source* as version-parameterized templates. `install` writes those files into a Kibana plugins directory and optionally builds the plugin. The build should also produce a distributable artifact (zip/archive) or a Kibana Docker image.
- **Superset:** Decaf holds *patch scripts* (Python + Bash) that modify Superset's internal source files (`superset-frontend/src/embedded/index.tsx` and `superset-embedded-sdk/src/index.ts`). `install` materializes the patch/build scripts, clones the Superset source (or uses an existing checkout), applies the patches, builds the SDK + frontend, and optionally produces a Docker image. Decaf does not generate new Superset source files — it patches existing ones.

### 4.2 Shared contract (`contract.ts`)

A DOM-free contract implemented by both plugins:

```ts
export const EMBED_MESSAGE_TYPE = {
  SWITCH: "ORG_DASHBOARD_EMBED_SWITCH_DASHBOARD",
  READY: "ORG_DASHBOARD_EMBED_READY",
  RENDERED: "ORG_DASHBOARD_EMBED_RENDERED",
  ERROR: "ORG_DASHBOARD_EMBED_ERROR",
} as const;

export interface DashboardQuery { language: "kuery" | "lucene"; query: string; }
export interface DashboardTimeRange { from: string; to: string; }

export interface SwitchDashboardPayload {
  dashboardId: string;
  timeRange?: DashboardTimeRange;
  query?: DashboardQuery;
  filters?: unknown[];
  /** Superset-only: dashboard-scoped guest token. Kibana ignores this. */
  guestToken?: string;
}

export interface SwitchDashboardMessage extends SwitchDashboardPayload {
  type: typeof EMBED_MESSAGE_TYPE.SWITCH;
}

export interface EmbedReadyMessage { type: typeof EMBED_MESSAGE_TYPE.READY; dashboardId: string | null; }
export interface EmbedRenderedMessage { type: typeof EMBED_MESSAGE_TYPE.RENDERED; dashboardId: string; }
export interface EmbedErrorMessage { type: typeof EMBED_MESSAGE_TYPE.ERROR; dashboardId: string | null; message: string; }
export type EmbedParentMessage = EmbedReadyMessage | EmbedRenderedMessage | EmbedErrorMessage;

// DOM-free message target. Both Kibana and Superset use the same interface;
// each tool uses a different mechanism:
//   - Kibana: iframe.contentWindow → postMessage
//   - Superset: embedded SDK EmbeddedDashboard handle → switchDashboard
// At least one method must be present; each plugin checks for what it needs.
export interface EmbedMessageTarget {
  postMessage?(message: unknown, targetOrigin: string): void;
  switchDashboard?(dashboardId: string, guestToken?: string): Promise<unknown>;
}

export interface EmbedViewOptions {
  showTimeFilter?: boolean;
  showQueryInput?: boolean;
  showFilterBar?: boolean;
  hidePanelTitles?: boolean;
  timeRange?: DashboardTimeRange;
}

export interface EmbedUrlOptions {
  host: string;            // e.g. "ptp.host"
  basePath?: string;       // e.g. "kibana"
  dashboardId: string;
  parentOrigin: string;
  view?: EmbedViewOptions;
}

export interface DashboardEmbedPluginDescriptor {
  id: string;
  appId: string;
  version: string;
  targetVersion: string;   // BI tool version (kibana/superset)
  tool: "kibana" | "superset";
}

export interface PluginInstallOptions {
  targetPath: string;      // directory to materialize the plugin into (default: integrations/plugins/kibana or integrations/plugins/superset)
  targetVersion?: string;  // overrides descriptor.targetVersion
  build?: boolean;         // attempt to build the plugin after writing (kibana only meaningful)
  overwrite?: boolean;
}

export interface PluginInstallResult {
  pluginPath: string;
  descriptor: DashboardEmbedPluginDescriptor;
  files: string[];
  built: boolean;
  buildOutput?: string;
}

export interface DashboardEmbedPlugin {
  readonly descriptor: DashboardEmbedPluginDescriptor;
  manifest(targetVersion?: string): Record<string, unknown>;
  buildEmbedUrl(options: EmbedUrlOptions): string;
  createSwitchDashboardMessage(payload: SwitchDashboardPayload): SwitchDashboardMessage;
  sendSwitchDashboardMessage(target: EmbedMessageTarget, payload: SwitchDashboardPayload, targetOrigin: string): void;
  install(options: PluginInstallOptions): Promise<PluginInstallResult>;
}
```

Both `KibanaDashboardEmbedPlugin` and `SupersetDashboardEmbedPlugin` `implements DashboardEmbedPlugin`.

### 4.3 Kibana plugin

- `manifest.ts` → `buildKibanaManifest(targetVersion)` returns the `kibana.json` object (`id: "orgDashboardEmbed"`, `kibanaVersion: targetVersion`, `requiredPlugins: ["dashboard","embeddable","data"]`).
- `templates.ts` → version-parameterized source strings for: `kibana.json`, `tsconfig.json`, `public/index.ts`, `public/plugin.tsx`, `public/application.tsx`, `public/types.ts`, `server/index.ts`, `server/plugin.ts`. The reference source (below, §8) is embedded here.
- `installer.ts` → `KibanaDashboardEmbedPlugin`:
  - `buildEmbedUrl` → `${protocol? no—host only}/${basePath||kibana}/app/org_dashboard_embed?dashboardId=...&parentOrigin=...` (+ optional view params).
  - `install` → writes all template files to `targetPath/org_dashboard_embed/` (default `targetPath` = `integrations/plugins/kibana`), baking `targetVersion` into `kibana.json`; when `build: true`, spawns `yarn build` in the plugin dir and captures output (best-effort; documented that real builds require the Kibana repo).
- `host.ts` → convenience `buildKibanaEmbedUrl(...)` and `sendKibanaSwitchDashboardMessage(...)`.

### 4.4 Superset plugin

Same API as Kibana, but the "plugin" is a **patch-and-build** strategy rather than generated source:

- **What it patches:**
  - `superset-frontend/src/embedded/index.tsx` — adds a `switchDashboard` method to Superset's existing Switchboard channel. Replaces only `DashboardPage`. Keeps the iframe element, document, `contentWindow`, React runtime, and message channel alive.
  - `superset-embedded-sdk/src/index.ts` — adds `embeddedDashboard.switchDashboard(dashboardId)`. Requests a guest token for the selected dashboard. Refreshes future guest tokens for the currently selected dashboard.
- **Why patches:** Superset's embedded SDK officially creates an iframe and uses a guest-token callback. The native embedded frontend already uses Switchboard and renders `DashboardPage`; the patch extends those existing mechanisms. These are internal source files, so the patch must be applied against the exact Superset release deployed in the environment.
- `manifest.ts` → `buildSupersetManifest(targetVersion)` returns a manifest describing the embed strategy (embed strategy: iframe, status: patched, target version).
- `templates.ts` → string templates for all patch and build scripts:
  - `patches/apply_superset_6_1_patch.py` — Python patch application script (regex-based, idempotent).
  - `patches/verify_patch.sh` — Bash verification script.
  - `build/build-sdk.sh` — builds the patched embedded SDK.
  - `build/build-superset-frontend.sh` — builds the patched Superset frontend.
  - `build/patch-and-build.sh` — combined patch + verify + build.
  - `build/build-docker-image.sh` — patch + verify + Docker image build (lean target).
- `installer.ts` → `SupersetDashboardEmbedPlugin implements DashboardEmbedPlugin`:
  - `buildEmbedUrl` → Superset embedded URL: `${host}/${basePath}/embedded/${embeddedId}` (the `dashboardId` field in `EmbedUrlOptions` is the embedded-configuration UUID for Superset).
  - `sendSwitchDashboardMessage` → delegates to `target.switchDashboard(dashboardId, guestToken)` (the Superset SDK handle).
  - `install` → materializes the patch/build scripts into `targetPath/` (default `targetPath` = `integrations/plugins/superset`), then (when `build: true`):
    1. Clone Superset source (or use `supersetSourcePath` if provided).
    2. Apply the patch script.
    3. Verify the patch.
    4. Build the SDK.
    5. Build the frontend.
    6. Optionally build a Docker image (when `dockerImageTag` is provided).
  - Both the SDK and frontend builds are compiled from the patched source tree. The patched SDK must be packed and installed into the Angular application (`npm pack` + `npm install <tgz>`).
- `host.ts` → convenience `buildSupersetEmbedUrl(...)` and `sendSupersetSwitchDashboardMessage(...)`.

**Security constraints (from the reference implementation):**
- The `switchDashboard` method is exposed only through Superset's existing Switchboard MessageChannel — no new unrestricted `window.addEventListener('message')` handler is added.
- The host application must obtain a guest token for the target dashboard.
- Superset's normal Allowed Domains validation remains in effect.
- The guest-token endpoint must not trust a tenant/organization identifier supplied by Angular; `organizationId` comes from the authenticated user, not the request body.
- The initial URL uses an embedded-dashboard configuration UUID; later switches use actual dashboard UUIDs accepted by `DashboardPage`. These identifiers are not interchangeable.

**Behavior boundaries (what is preserved vs. reset on switch):**

Preserved: iframe DOM element, `contentWindow`, iframe document, Superset JS runtime, SDK MessageChannel, theme/embedding context.

Reset: `DashboardPage`, dashboard-local React state, chart components, dashboard metadata, dashboard-specific filter state.

"No iframe reload" means the browser does not navigate or reconstruct the embedded Superset application; the dashboard itself must still reload its metadata and charts.

### 4.6 `.gitignore` policy for install output directories

The `install()` method generates files into `integrations/plugins/kibana/` and `integrations/plugins/superset/`. These directories contain both **generated artifacts** (should NOT be committed) and **curated configuration** (should be committed).

Each output directory contains a tracked `.gitignore` that ignores everything by default and re-includes only the curated files:

**`integrations/plugins/kibana/.gitignore`:**
```gitignore
# Ignore everything by default
*

# Re-include the .gitignore itself
!.gitignore

# Re-include curated configuration (Dockerfiles, compose, host pages, scripts)
!Dockerfile
!docker-compose.yml
!kibana.yml
!setup-dashboards.sh
!dashboards.json
!host/
!host/**

# Everything else (generated plugin source, build artifacts, zips,
# node_modules) remains ignored
```

**`integrations/plugins/superset/.gitignore`:**
```gitignore
# Ignore everything by default
*

# Re-include the .gitignore itself
!.gitignore

# Re-include curated configuration (Dockerfiles, compose, config, host pages, scripts)
!Dockerfile
!docker-compose.yml
!superset_config.py
!setup-dashboards.sh
!dashboards.json
!host/
!host/**

# Everything else (generated patch scripts, cloned Superset source,
# build artifacts, node_modules) remains ignored
```

**Rationale:** The generated plugin source (`org_dashboard_embed/`, `org_dashboard_embed_superset/`) is reproducible from `install()` at any time and should not bloat the repository. The curated files (Dockerfiles, compose files, host HTML pages, setup scripts) are hand-written infrastructure for e2e testing and deployment, and must be tracked.

## 6. Open Questions / Risks

*   Superset has no Kibana-style native plugin system; the "plugin" is a patch-and-build strategy that modifies Superset's internal embedded frontend + SDK source. The patch must be maintained as a downstream patch tied to the exact Superset release.
*   Kibana plugins must be built within the Kibana repo against the exact version. `install({ build: true })` attempts `yarn build` but may require the Kibana plugin-helpers environment; this is documented and best-effort. The Kibana build should also produce a distributable artifact (archive or Docker image).
*   Should the message protocol be shared from a single `./plugins` import to guarantee host/plugin parity? Yes — `./plugins` re-exports the contract; each tool subpath re-exports it too.
*   Risk: Kibana plugin APIs vary by minor release and are not backwards compatible. The installer bakes `targetVersion` into `kibana.json` and the templates are version-conscious where possible.
*   Risk: Superset's `EmbeddedLazyDashboardPage` may appear as `EmbededLazyDashboardPage` (typo) in older 6.1 patch releases; the patch script handles both names.
*   Risk: The Superset patch uses regex matching against internal source formatting; minor formatting differences between 6.1.x releases are handled with multiple anchor candidates, but the patch must be verified against the exact deployed release.
*   Playwright e2e visual tests require live Kibana and Superset instances; they are gated behind environment availability and use playwright-mcp for screenshot-based validation.

### 8.6 `public/application.tsx`
```tsx
import React, { useCallback, useEffect, useRef, useState } from 'react';
import type { MountAppArgs } from './types';

type DashboardQuery = {
  language: 'kuery' | 'lucene';
  query: string;
};

type DashboardTimeRange = {
  from: string;
  to: string;
};

type SwitchDashboardMessage = {
  type: 'ORG_DASHBOARD_EMBED_SWITCH_DASHBOARD';
  dashboardId: string;
  timeRange?: DashboardTimeRange;
  query?: DashboardQuery;
  filters?: unknown[];
};

type ParentReadyMessage = {
  type: 'ORG_DASHBOARD_EMBED_READY';
  dashboardId: string | null;
};

type ParentRenderedMessage = {
  type: 'ORG_DASHBOARD_EMBED_RENDERED';
  dashboardId: string;
};

type ParentErrorMessage = {
  type: 'ORG_DASHBOARD_EMBED_ERROR';
  dashboardId: string | null;
  message: string;
};

type ParentMessage =
  | ParentReadyMessage
  | ParentRenderedMessage
  | ParentErrorMessage;

const DEFAULT_ALLOWED_PARENT_ORIGINS: string[] = [
  window.location.origin
];

function getInitialDashboardId(): string | null {
  const params = new URLSearchParams(window.location.search);
  return params.get('dashboardId');
}

function getAllowedParentOrigins(): string[] {
  const params = new URLSearchParams(window.location.search);
  const raw = params.get('parentOrigin');

  if (!raw) {
    return DEFAULT_ALLOWED_PARENT_ORIGINS;
  }

  try {
    const decoded = decodeURIComponent(raw);
    const origins = decoded
      .split(',')
      .map((origin) => origin.trim())
      .filter(Boolean);

    return origins.length > 0 ? origins : DEFAULT_ALLOWED_PARENT_ORIGINS;
  } catch {
    return DEFAULT_ALLOWED_PARENT_ORIGINS;
  }
}

function isSwitchDashboardMessage(data: unknown): data is SwitchDashboardMessage {
  if (!data || typeof data !== 'object') {
    return false;
  }

  const message = data as Partial<SwitchDashboardMessage>;

  return (
    message.type === 'ORG_DASHBOARD_EMBED_SWITCH_DASHBOARD' &&
    typeof message.dashboardId === 'string' &&
    message.dashboardId.length > 0
  );
}

function postToParent(message: ParentMessage, targetOrigin: string) {
  window.parent.postMessage(message, targetOrigin);
}

export function OrgDashboardEmbedApp({
  coreStart,
  depsStart
}: MountAppArgs) {
  const rootRef = useRef<HTMLDivElement | null>(null);
  const mountedDashboardRef = useRef<any>(null);
  const allowedParentOriginsRef = useRef<string[]>(getAllowedParentOrigins());
  const lastParentOriginRef = useRef<string>(window.location.origin);

  const [dashboardId, setDashboardId] = useState<string | null>(
    getInitialDashboardId()
  );

  const [loading, setLoading] = useState(false);

  useEffect(() => {
    coreStart.chrome.setIsVisible(false);
  }, [coreStart]);

  const destroyCurrentDashboard = useCallback(() => {
    if (mountedDashboardRef.current?.destroy) {
      mountedDashboardRef.current.destroy();
    }

    mountedDashboardRef.current = null;

    if (rootRef.current) {
      rootRef.current.innerHTML = '';
    }
  }, []);

  const applySharedDashboardState = useCallback(
    (message: SwitchDashboardMessage) => {
      if (message.timeRange) {
        depsStart.data.query.timefilter.timefilter.setTime(message.timeRange);
      }

      if (message.query) {
        depsStart.data.query.queryString.setQuery(message.query);
      }

      if (message.filters) {
        depsStart.data.query.filterManager.setFilters(message.filters as any);
      }
    },
    [depsStart.data]
  );

  useEffect(() => {
    const onMessage = (event: MessageEvent) => {
      if (!allowedParentOriginsRef.current.includes(event.origin)) {
        return;
      }

      if (!isSwitchDashboardMessage(event.data)) {
        return;
      }

      lastParentOriginRef.current = event.origin;

      applySharedDashboardState(event.data);
      setDashboardId(event.data.dashboardId);
    };

    window.addEventListener('message', onMessage);

    postToParent(
      {
        type: 'ORG_DASHBOARD_EMBED_READY',
        dashboardId
      },
      lastParentOriginRef.current
    );

    return () => window.removeEventListener('message', onMessage);
  }, [applySharedDashboardState, dashboardId]);

  useEffect(() => {
    if (!dashboardId || !rootRef.current) {
      return;
    }

    let cancelled = false;

    async function renderDashboard() {
      setLoading(true);

      try {
        destroyCurrentDashboard();

        const factory =
          depsStart.embeddable.getEmbeddableFactory?.('dashboard') ||
          depsStart.embeddable.getEmbeddableFactory?.('dashboard_container');

        if (!factory) {
          throw new Error('Kibana dashboard embeddable factory was not found.');
        }

        const embeddable = await factory.create({
          id: dashboardId,
          savedObjectId: dashboardId,
          viewMode: 'view',
          hidePanelTitles: false,
          useMargins: true,
          syncColors: true,
          syncCursor: true,
          syncTooltips: true,
          timeRange: depsStart.data.query.timefilter.timefilter.getTime(),
          query: depsStart.data.query.queryString.getQuery(),
          filters: depsStart.data.query.filterManager.getFilters()
        } as any);

        if (cancelled) {
          embeddable.destroy?.();
          return;
        }

        embeddable.render(rootRef.current!);
        mountedDashboardRef.current = embeddable;

        postToParent(
          {
            type: 'ORG_DASHBOARD_EMBED_RENDERED',
            dashboardId
          },
          lastParentOriginRef.current
        );
      } catch (error) {
        const message =
          error instanceof Error ? error.message : 'Unknown dashboard error';

        if (rootRef.current) {
          rootRef.current.innerHTML = `
            <div style="
              padding: 24px;
              font-family: sans-serif;
              color: #bd271e;
            ">
              Failed to render dashboard: ${message}
            </div>
          `;
        }

        postToParent(
          {
            type: 'ORG_DASHBOARD_EMBED_ERROR',
            dashboardId,
            message
          },
          lastParentOriginRef.current
        );
      } finally {
        if (!cancelled) {
          setLoading(false);
        }
      }
    }

    renderDashboard();

    return () => {
      cancelled = true;
    };
  }, [dashboardId, depsStart, destroyCurrentDashboard]);

  useEffect(() => {
    return () => {
      destroyCurrentDashboard();
    };
  }, [destroyCurrentDashboard]);

  return (
    <div
      style={{
        position: 'fixed',
        inset: 0,
        width: '100vw',
        height: '100vh',
        overflow: 'hidden',
        background: '#fff'
      }}
    >
      {loading && (
        <div
          style={{
            position: 'absolute',
            inset: 0,
            zIndex: 10,
            display: 'flex',
            alignItems: 'center',
            justifyContent: 'center',
            fontFamily: 'sans-serif',
            background: '#fff'
          }}
        >
          Loading dashboard…
        </div>
      )}

      <div
        ref={rootRef}
        style={{
          position: 'absolute',
          inset: 0,
          width: '100%',
          height: '100%'
        }}
      />
    </div>
  );
}
```

### 9.1 Patch application script — `patches/apply_superset_6_1_patch.py`

```python
#!/usr/bin/env python3

from __future__ import annotations

import argparse
import re
import sys
from pathlib import Path


FRONTEND_FILE = Path("superset-frontend/src/embedded/index.tsx")
SDK_FILE = Path("superset-embedded-sdk/src/index.ts")


class PatchError(RuntimeError):
    pass


def replace_once(
    content: str,
    old: str,
    new: str,
    description: str,
) -> str:
    count = content.count(old)

    if count != 1:
        raise PatchError(
            f"{description}: expected exactly one occurrence, found {count}"
        )

    return content.replace(old, new, 1)


def replace_regex_once(
    content: str,
    pattern: re.Pattern[str],
    replacement: str,
    description: str,
) -> str:
    updated, count = pattern.subn(replacement, content, count=1)

    if count != 1:
        raise PatchError(
            f"{description}: expected exactly one match, found {count}"
        )

    return updated


def patch_react_import(content: str) -> str:
    """
    Superset 6.1 patch releases may have slightly different React imports.

    Add useState only when it is not already present.
    """

    react_import_pattern = re.compile(
        r"import\s*\{\s*([^}]+)\s*\}\s*from\s*'react';"
    )

    match = react_import_pattern.search(content)

    if not match:
        raise PatchError("Could not locate the named React import")

    imports = [
        value.strip()
        for value in match.group(1).replace("\n", " ").split(",")
        if value.strip()
    ]

    required_imports = ["lazy", "Suspense", "useEffect", "useState"]

    for required_import in required_imports:
        if required_import not in imports:
            imports.append(required_import)

    replacement = (
        "import {\n  "
        + ",\n  ".join(imports)
        + ",\n} from 'react';"
    )

    return (
        content[: match.start()]
        + replacement
        + content[match.end() :]
    )


def locate_embedded_component(
    content: str,
) -> tuple[re.Match[str], str]:
    """
    Some older source versions contained the typo
    `EmbededLazyDashboardPage`. Later versions use
    `EmbeddedLazyDashboardPage`.
    """

    names = [
        "EmbeddedLazyDashboardPage",
        "EmbededLazyDashboardPage",
    ]

    for name in names:
        pattern = re.compile(
            rf"const {name} = \(\) => \{{.*?\n\}};\n"
            rf"(?=const EmbeddedRoute)",
            re.DOTALL,
        )

        match = pattern.search(content)

        if match:
            return match, name

    raise PatchError(
        "Could not find EmbeddedLazyDashboardPage before EmbeddedRoute"
    )


def patch_frontend(frontend_path: Path) -> None:
    content = frontend_path.read_text(encoding="utf-8")

    if "SUPERSET_SWITCHABLE_EMBED_PATCH" in content:
        print(f"Already patched: {frontend_path}")
        return

    content = patch_react_import(content)

    component_match, component_name = locate_embedded_component(
        content
    )

    replacement_component = f"""// SUPERSET_SWITCHABLE_EMBED_PATCH
//
// Allows the existing embedded Superset document to replace DashboardPage
// without navigating or recreating the iframe.
//
// Security:
// - This method is exposed only through Superset's existing Switchboard
//   MessageChannel.
// - The host application must obtain a guest token for the target dashboard.
// - Superset's normal Allowed Domains validation remains in effect.

interface SwitchDashboardPayload {{
  dashboardId: string;
  guestToken: string;
}}

interface SwitchDashboardResult {{
  dashboardId: string;
  accepted: true;
}}

type DashboardSwitchHandler = (
  payload: SwitchDashboardPayload,
) => Promise<SwitchDashboardResult>;

let dashboardSwitchHandler: DashboardSwitchHandler | undefined;

const {component_name} = () => {{
  const uiConfig = useUiConfig();

  const [dashboardId, setDashboardId] = useState<string | null>(
    bootstrapData.embedded!.dashboard_id,
  );

  /*
   * Register a handler used by the Switchboard method below.
   *
   * Setting dashboardId to null first unmounts DashboardPage before
   * SupersetClient is reconfigured with the new token.
   */
  useEffect(() => {{
    dashboardSwitchHandler = async ({{
      dashboardId: requestedDashboardId,
      guestToken,
    }}: SwitchDashboardPayload) => {{
      const nextDashboardId = requestedDashboardId.trim();

      if (!nextDashboardId) {{
        throw new Error(
          'dashboardId must be a non-empty string',
        );
      }}

      if (
        typeof guestToken !== 'string' ||
        guestToken.trim().length === 0
      ) {{
        throw new Error(
          'guestToken must be a non-empty string',
        );
      }}

      /*
       * Unmount the current DashboardPage.
       *
       * This avoids old dashboard effects and requests continuing while
       * setupGuestClient replaces the guest token used by SupersetClient.
       */
      setDashboardId(null);

      /*
       * Reset the guest unauthorized warning so an authorization failure
       * for a previous dashboard does not suppress a warning for the next.
       */
      displayedUnauthorizedToast = false;

      /*
       * Reconfigure SupersetClient using the new dashboard-specific token.
       */
      setupGuestClient(guestToken);

      /*
       * Give React one render frame to dispose of the old DashboardPage.
       */
      await new Promise<void>(resolve => {{
        window.requestAnimationFrame(() => resolve());
      }});

      /*
       * Mount a fresh DashboardPage in the same embedded React application.
       */
      setDashboardId(nextDashboardId);

      return {{
        dashboardId: nextDashboardId,
        accepted: true,
      }};
    }};

    return () => {{
      dashboardSwitchHandler = undefined;
    }};
  }}, []);

  /*
   * Preserve Superset's existing data-mask event forwarding.
   */
  useEffect(() => {{
    if (!uiConfig?.emitDataMasks) {{
      return undefined;
    }}

    let previousDataMask = store.getState().dataMask;

    return store.subscribe(() => {{
      const currentDataMask = store.getState().dataMask;

      if (previousDataMask !== currentDataMask) {{
        Switchboard.emit('observeDataMask', {{
          ...currentDataMask,
          ...getDataMaskChangeTrigger(
            currentDataMask,
            previousDataMask,
          ),
        }});

        previousDataMask = currentDataMask;
      }}
    }});
  }}, [uiConfig?.emitDataMasks]);

  if (!dashboardId) {{
    return <Loading />;
  }}

  /*
   * The key forces a clean DashboardPage lifecycle while the surrounding
   * embedded application and iframe document remain alive.
   */
  return (
    <LazyDashboardPage
      key={{dashboardId}}
      idOrSlug={{dashboardId}}
    />
  );
}};
"""

    content = (
        content[: component_match.start()]
        + replacement_component
        + content[component_match.end() :]
    )

    switchboard_anchor_candidates = [
        (
            "    Switchboard.defineMethod("
            "'getScrollSize', embeddedApi.getScrollSize);"
        ),
        (
            "    Switchboard.defineMethod(\n"
            "      'getScrollSize',\n"
            "      embeddedApi.getScrollSize,\n"
            "    );"
        ),
    ]

    switchboard_method = """    Switchboard.defineMethod(
      'switchDashboard',
      async (
        payload: SwitchDashboardPayload,
      ): Promise<SwitchDashboardResult> => {
        if (!dashboardSwitchHandler) {
          throw new Error(
            'The embedded dashboard is not ready to switch',
          );
        }

        return dashboardSwitchHandler(payload);
      },
    );

"""

    anchor_found = False

    for anchor in switchboard_anchor_candidates:
        if content.count(anchor) == 1:
            content = content.replace(
                anchor,
                switchboard_method + anchor,
                1,
            )
            anchor_found = True
            break

    if not anchor_found:
        raise PatchError(
            "Could not locate the getScrollSize Switchboard method"
        )

    frontend_path.write_text(content, encoding="utf-8")
    print(f"Patched: {frontend_path}")


def patch_guest_token_fetch_type(content: str) -> str:
    candidates = [
        "export type GuestTokenFetchFn = () => Promise<string>;",
        (
            "export type GuestTokenFetchFn = "
            "() => Promise<string>;"
        ),
    ]

    replacement = """// SUPERSET_SWITCHABLE_EMBED_SDK_PATCH
//
// dashboardId is undefined for the initial dashboard bootstrap.
// After a successful dashboard switch, token refreshes receive the active
// dashboard UUID.
export type GuestTokenFetchFn = (
  dashboardId?: string,
) => Promise<string>;"""

    for candidate in candidates:
        if content.count(candidate) == 1:
            return content.replace(
                candidate,
                replacement,
                1,
            )

    raise PatchError("Could not locate GuestTokenFetchFn")


def patch_embedded_dashboard_type(content: str) -> str:
    """
    Adds switchDashboard immediately before the end of the
    EmbeddedDashboard type.
    """

    type_pattern = re.compile(
        r"(export\s+(?:interface|type)\s+EmbeddedDashboard"
        r".*?\{)(.*?)(\n\};)",
        re.DOTALL,
    )

    match = type_pattern.search(content)

    if not match:
        raise PatchError(
            "Could not locate the EmbeddedDashboard public type"
        )

    body = match.group(2)

    if "switchDashboard:" in body:
        return content

    method = """
  /**
   * Replaces DashboardPage in the existing iframe document.
   *
   * The value must be the target dashboard UUID/id accepted by
   * DashboardPage, not the embedded-configuration UUID used in the
   * initial /embedded/:uuid URL.
   */
  switchDashboard: (
    dashboardId: string,
  ) => Promise<{
    dashboardId: string;
    accepted: true;
  }>;
"""

    updated_type = (
        match.group(1)
        + body.rstrip()
        + "\n"
        + method.rstrip()
        + match.group(3)
    )

    return (
        content[: match.start()]
        + updated_type
        + content[match.end() :]
    )


def patch_initial_guest_token_fetch(content: str) -> str:
    """
    The initial call remains compatible because dashboardId is optional.
    """

    candidates = [
        "fetchGuestToken(),",
        "await fetchGuestToken(),",
    ]

    for candidate in candidates:
        if content.count(candidate) >= 1:
            return content.replace(
                candidate,
                candidate.replace(
                    "fetchGuestToken()",
                    "fetchGuestToken(undefined)",
                ),
                1,
            )

    raise PatchError(
        "Could not locate the initial fetchGuestToken call"
    )


def patch_guest_token_refresh(content: str) -> str:
    """
    Superset 6.1 source may express the refresh function with minor
    formatting differences, so match the function structurally.
    """

    patterns = [
        re.compile(
            r"async function refreshGuestToken\(\) \{\s*"
            r"const newGuestToken = await fetchGuestToken\(\);\s*"
            r"ourPort\.emit\("
            r"'guestToken',\s*\{\s*guestToken:\s*newGuestToken\s*\}"
            r"\);\s*"
            r"setTimeout\("
            r"refreshGuestToken,\s*"
            r"getGuestTokenRefreshTiming\(newGuestToken\)"
            r"\);\s*"
            r"\}",
            re.DOTALL,
        ),
        re.compile(
            r"const refreshGuestToken = async \(\) => \{\s*"
            r"const newGuestToken = await fetchGuestToken\(\);\s*"
            r"ourPort\.emit\("
            r"'guestToken',\s*\{\s*guestToken:\s*newGuestToken\s*\}"
            r"\);\s*"
            r"setTimeout\("
            r"refreshGuestToken,\s*"
            r"getGuestTokenRefreshTiming\(newGuestToken\)"
            r"\);\s*"
            r"\};",
            re.DOTALL,
        ),
    ]

    replacement = """let activeDashboardId: string | undefined;

  async function refreshGuestToken() {
    const newGuestToken = await fetchGuestToken(
      activeDashboardId,
    );

    ourPort.emit('guestToken', {
      guestToken: newGuestToken,
    });

    setTimeout(
      refreshGuestToken,
      getGuestTokenRefreshTiming(newGuestToken),
    );
  }"""

    for pattern in patterns:
        updated, count = pattern.subn(
            replacement,
            content,
            count=1,
        )

        if count == 1:
            return updated

    raise PatchError(
        "Could not locate the guest-token refresh function"
    )


def patch_sdk_functions(content: str) -> str:
    anchor_candidates = [
        (
            "  const getScrollSize = () => "
            "ourPort.get<Size>('getScrollSize');"
        ),
        (
            "  const getScrollSize = () =>\n"
            "    ourPort.get<Size>('getScrollSize');"
        ),
    ]

    switch_function = """  const switchDashboard = async (
    dashboardId: string,
  ): Promise<{
    dashboardId: string;
    accepted: true;
  }> => {
    const normalizedDashboardId = dashboardId.trim();

    if (!normalizedDashboardId) {
      throw new Error(
        'dashboardId must be a non-empty string',
      );
    }

    /*
     * Generate a token that explicitly authorizes the target dashboard.
     */
    const guestToken = await fetchGuestToken(
      normalizedDashboardId,
    );

    /*
     * Send the dashboard and token over the already-established private
     * MessageChannel. This does not navigate the iframe.
     */
    const result = await ourPort.get<{
      dashboardId: string;
      accepted: true;
    }>('switchDashboard', {
      dashboardId: normalizedDashboardId,
      guestToken,
    });

    /*
     * Only change the active refresh target after Superset accepted the
     * switch. A failed switch therefore preserves the prior token scope.
     */
    activeDashboardId = normalizedDashboardId;

    return result;
  };

"""

    for anchor in anchor_candidates:
        if content.count(anchor) == 1:
            return content.replace(
                anchor,
                switch_function + anchor,
                1,
            )

    raise PatchError(
        "Could not locate the SDK getScrollSize function"
    )


def patch_sdk_return_object(content: str) -> str:
    """
    Find the return object of embedDashboard and add switchDashboard beside
    the other public methods.
    """

    candidates = [
        "    setThemeMode,\n  };",
        "    setThemeMode,\n    unmount,\n  };",
        "    unmount,\n    setThemeMode,\n  };",
    ]

    for candidate in candidates:
        if content.count(candidate) == 1:
            lines = candidate.splitlines()

            closing = lines.pop()
            body = "\n".join(lines)

            return content.replace(
                candidate,
                body
                + "\n"
                + "    switchDashboard,\n"
                + closing,
                1,
            )

    raise PatchError(
        "Could not locate the EmbeddedDashboard return object"
    )


def patch_sdk(sdk_path: Path) -> None:
    content = sdk_path.read_text(encoding="utf-8")

    if "SUPERSET_SWITCHABLE_EMBED_SDK_PATCH" in content:
        print(f"Already patched: {sdk_path}")
        return

    content = patch_guest_token_fetch_type(content)
    content = patch_embedded_dashboard_type(content)
    content = patch_initial_guest_token_fetch(content)
    content = patch_guest_token_refresh(content)
    content = patch_sdk_functions(content)
    content = patch_sdk_return_object(content)

    sdk_path.write_text(content, encoding="utf-8")
    print(f"Patched: {sdk_path}")


def main() -> int:
    parser = argparse.ArgumentParser(
        description=(
            "Apply the switchable-dashboard patch to a "
            "Superset 6.1.x source checkout."
        )
    )

    parser.add_argument(
        "superset_root",
        type=Path,
        help="Path to the Apache Superset source checkout",
    )

    args = parser.parse_args()
    root = args.superset_root.resolve()

    frontend_path = root / FRONTEND_FILE
    sdk_path = root / SDK_FILE

    missing = [
        path
        for path in [frontend_path, sdk_path]
        if not path.exists()
    ]

    if missing:
        print(
            "The target does not appear to be a compatible "
            "Superset source checkout.",
            file=sys.stderr,
        )

        for missing_path in missing:
            print(f"Missing: {missing_path}", file=sys.stderr)

        return 2

    try:
        patch_frontend(frontend_path)
        patch_sdk(sdk_path)
    except PatchError as error:
        print(f"Patch failed: {error}", file=sys.stderr)
        return 1

    print("Patch completed successfully.")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

### 9.7 Expected Superset frontend implementation (inserted section)

The patch script inserts the following logic into `superset-frontend/src/embedded/index.tsx`:

```tsx
// SUPERSET_SWITCHABLE_EMBED_PATCH
//
// Allows the existing embedded Superset document to replace DashboardPage
// without navigating or recreating the iframe.
//
// Security:
// - This method is exposed only through Superset's existing Switchboard
//   MessageChannel.
// - The host application must obtain a guest token for the target dashboard.
// - Superset's normal Allowed Domains validation remains in effect.

interface SwitchDashboardPayload {
  dashboardId: string;
  guestToken: string;
}

interface SwitchDashboardResult {
  dashboardId: string;
  accepted: true;
}

type DashboardSwitchHandler = (
  payload: SwitchDashboardPayload,
) => Promise<SwitchDashboardResult>;

let dashboardSwitchHandler:
  | DashboardSwitchHandler
  | undefined;

const EmbeddedLazyDashboardPage = () => {
  const uiConfig = useUiConfig();

  const [dashboardId, setDashboardId] = useState<
    string | null
  >(bootstrapData.embedded!.dashboard_id);

  useEffect(() => {
    dashboardSwitchHandler = async ({
      dashboardId: requestedDashboardId,
      guestToken,
    }: SwitchDashboardPayload) => {
      const nextDashboardId =
        requestedDashboardId.trim();

      if (!nextDashboardId) {
        throw new Error(
          'dashboardId must be a non-empty string',
        );
      }

      if (
        typeof guestToken !== 'string' ||
        guestToken.trim().length === 0
      ) {
        throw new Error(
          'guestToken must be a non-empty string',
        );
      }

      setDashboardId(null);

      displayedUnauthorizedToast = false;

      setupGuestClient(guestToken);

      await new Promise<void>(resolve => {
        window.requestAnimationFrame(() => resolve());
      });

      setDashboardId(nextDashboardId);

      return {
        dashboardId: nextDashboardId,
        accepted: true,
      };
    };

    return () => {
      dashboardSwitchHandler = undefined;
    };
  }, []);

  useEffect(() => {
    if (!uiConfig?.emitDataMasks) {
      return undefined;
    }

    let previousDataMask = store.getState().dataMask;

    return store.subscribe(() => {
      const currentDataMask =
        store.getState().dataMask;

      if (previousDataMask !== currentDataMask) {
        Switchboard.emit('observeDataMask', {
          ...currentDataMask,
          ...getDataMaskChangeTrigger(
            currentDataMask,
            previousDataMask,
          ),
        });

        previousDataMask = currentDataMask;
      }
    });
  }, [uiConfig?.emitDataMasks]);

  if (!dashboardId) {
    return <Loading />;
  }

  return (
    <LazyDashboardPage
      key={dashboardId}
      idOrSlug={dashboardId}
    />
  );
};
```

Inside the existing embedded setup, the patch adds:

```tsx
Switchboard.defineMethod(
  'switchDashboard',
  async (
    payload: SwitchDashboardPayload,
  ): Promise<SwitchDashboardResult> => {
    if (!dashboardSwitchHandler) {
      throw new Error(
        'The embedded dashboard is not ready to switch',
      );
    }

    return dashboardSwitchHandler(payload);
  },
);
```

Do not add a new unrestricted `window.addEventListener('message')` handler. Using Superset's existing Switchboard channel preserves the normal embedded handshake and origin-validation architecture.

### 9.8 Expected Embedded SDK implementation — `superset-embedded-sdk/src/index.ts`

**Guest-token callback type** — replace:
```ts
export type GuestTokenFetchFn = () => Promise<string>;
```
with:
```ts
// SUPERSET_SWITCHABLE_EMBED_SDK_PATCH
//
// dashboardId is undefined for the initial dashboard bootstrap.
// After a successful dashboard switch, token refreshes receive the active
// dashboard UUID.
export type GuestTokenFetchFn = (
  dashboardId?: string,
) => Promise<string>;
```

This remains source-compatible with callbacks that ignore their argument:
```ts
fetchGuestToken: () => loadInitialToken()
```
But it permits a dashboard-aware implementation:
```ts
fetchGuestToken: dashboardId =>
  loadTokenForDashboard(dashboardId)
```

**Public SDK method** — add to `EmbeddedDashboard`:
```ts
/**
 * Replaces DashboardPage in the existing iframe document.
 *
 * dashboardId is the target Superset dashboard UUID/id. It is not the
 * embedded configuration UUID used by the /embedded/:uuid URL.
 */
switchDashboard: (
  dashboardId: string,
) => Promise<{
  dashboardId: string;
  accepted: true;
}>;
```

**Active dashboard token state** — before the guest-token refresh function:
```ts
let activeDashboardId: string | undefined;
```

**Replace the refresh function** with:
```ts
async function refreshGuestToken() {
  const newGuestToken = await fetchGuestToken(
    activeDashboardId,
  );

  ourPort.emit('guestToken', {
    guestToken: newGuestToken,
  });

  setTimeout(
    refreshGuestToken,
    getGuestTokenRefreshTiming(newGuestToken),
  );
}
```

**Change the initial token request** from `fetchGuestToken()` to `fetchGuestToken(undefined)`.

**Add this function** beside the existing public API methods:
```ts
const switchDashboard = async (
  dashboardId: string,
): Promise<{
  dashboardId: string;
  accepted: true;
}> => {
  const normalizedDashboardId =
    dashboardId.trim();

  if (!normalizedDashboardId) {
    throw new Error(
      'dashboardId must be a non-empty string',
    );
  }

  /*
   * The backend validates the target dashboard against the authenticated
   * organization's dashboard allowlist and returns a dashboard-scoped
   * guest token.
   */
  const guestToken = await fetchGuestToken(
    normalizedDashboardId,
  );

  /*
   * This uses the iframe's existing MessageChannel. It does not change
   * iframe.src and does not create a replacement iframe.
   */
  const result = await ourPort.get<{
    dashboardId: string;
    accepted: true;
  }>('switchDashboard', {
    dashboardId: normalizedDashboardId,
    guestToken,
  });

  /*
   * Future scheduled token refreshes must target the newly selected
   * dashboard.
   */
  activeDashboardId = normalizedDashboardId;

  return result;
};
```

**Add the method to the returned SDK object:**
```ts
return {
  // Existing SDK methods...
  getScrollSize,
  getDashboardPermalink,
  getActiveTabs,
  observeDataMask,
  setThemeConfig,
  setThemeMode,
  unmount,

  // New method
  switchDashboard,
};
```

The initial URL still uses an embedded-dashboard configuration UUID. Later switches use actual dashboard UUIDs accepted by `DashboardPage`. Superset exposes separate APIs for embedded configuration and dashboard resources, so these identifiers should not be treated as interchangeable.

```ts
import { Injectable } from '@angular/core';

import {
  EmbeddedDashboard,
  embedDashboard,
} from '@superset-ui/embedded-sdk';

export interface MountSupersetOptions {
  /**
   * Initial Superset embedded-configuration UUID.
   *
   * This is the UUID used in /embedded/:uuid.
   */
  embeddedId: string;

  /**
   * Superset origin or reverse-proxy base URL.
   *
   * Examples:
   * - https://superset.example.com
   * - /superset
   */
  supersetDomain: string;

  mountPoint: HTMLElement;

  /**
   * dashboardId is undefined for initial bootstrap.
   *
   * After switching, it contains the selected dashboard UUID.
   */
  fetchGuestToken: (
    dashboardId?: string,
  ) => Promise<string>;
}

@Injectable({
  providedIn: 'root',
})
export class SupersetSwitchableService {
  private embeddedDashboard?: EmbeddedDashboard;

  async mount(
    options: MountSupersetOptions,
  ): Promise<void> {
    if (this.embeddedDashboard) {
      throw new Error(
        'A Superset dashboard is already mounted',
      );
    }

    this.embeddedDashboard = await embedDashboard({
      id: options.embeddedId,
      supersetDomain: options.supersetDomain,
      mountPoint: options.mountPoint,
      fetchGuestToken: options.fetchGuestToken,
      dashboardUiConfig: {
        hideTitle: true,
        hideTab: true,
        hideChartControls: true,
        filters: {
          visible: true,
          expanded: false,
        },
        urlParams: {
          standalone: '1',
        },
      },
      iframeTitle: 'Analytics dashboard',
    });
  }

  async switchDashboard(
    dashboardId: string,
  ): Promise<void> {
    if (!this.embeddedDashboard) {
      throw new Error(
        'Superset has not been mounted',
      );
    }

    await this.embeddedDashboard.switchDashboard(
      dashboardId,
    );
  }

  unmount(): void {
    this.embeddedDashboard?.unmount();
    this.embeddedDashboard = undefined;
  }
}
```

```ts
          this.mountPoint.nativeElement,
        fetchGuestToken: async dashboardId => {
          const response =
            await this.tokens.getGuestToken(
              dashboardId,
            );

          return response.token;
        },
      });

      this.loading = false;
      this.changeDetector.markForCheck();
    } catch (error) {
      this.setError(error);
    }
  }

    dashboardId: string,

    this.error = null;

      await this.superset.switchDashboard(
        dashboardId,
      );

      this.loading = false;
      this.changeDetector.markForCheck();

      this.setError(error);
```

### 9.17 NestJS Superset API service — `superset-api.service.ts`

```ts
import {
  BadGatewayException,
  Injectable,
  Logger,
} from '@nestjs/common';

import {
  ConfigService,
} from '@nestjs/config';

interface SupersetLoginResponse {
  access_token: string;
}

interface SupersetGuestTokenResponse {
  token: string;
}

export interface CreateGuestTokenInput {
  dashboardId: string;
  username: string;
  firstName: string;
  lastName: string;
  organizationId: string;
}

@Injectable()
export class SupersetApiService {
  private readonly logger = new Logger(
    SupersetApiService.name,
  );

  constructor(
    private readonly config:
      ConfigService,
  ) {}

  async createGuestToken(
    input: CreateGuestTokenInput,
  ): Promise<string> {
    const baseUrl = this.getBaseUrl();

    const accessToken =
      await this.getServiceAccessToken(baseUrl);

    const response = await fetch(
      `${baseUrl}/api/v1/security/guest_token/`,
      {
        method: 'POST',
        headers: {
          Authorization:
            `Bearer ${accessToken}`,
          'Content-Type':
            'application/json',
        },
        body: JSON.stringify({
          user: {
            username: input.username,
            first_name: input.firstName,
            last_name: input.lastName,
          },
          resources: [
            {
              type: 'dashboard',
              id: input.dashboardId,
            },
          ],
          rls: [
            {
              clause:
                this.buildOrganizationRlsClause(
                  input.organizationId,
                ),
            },
          ],
        }),
      },
    );

    if (!response.ok) {
      const responseBody =
        await response.text();

      this.logger.error(
        [
          'Superset guest-token request failed.',
          `Status: ${response.status}`,
          `Body: ${responseBody}`,
        ].join(' '),
      );

      throw new BadGatewayException(
        'Unable to create a Superset guest token',
      );
    }

    const result =
      (await response.json()) as
        SupersetGuestTokenResponse;

    if (!result.token) {
      throw new BadGatewayException(
        'Superset returned an empty guest token',
      );
    }

    return result.token;
  }

  private async getServiceAccessToken(
    baseUrl: string,
  ): Promise<string> {
    const response = await fetch(
      `${baseUrl}/api/v1/security/login`,
      {
        method: 'POST',
        headers: {
          'Content-Type':
            'application/json',
        },
        body: JSON.stringify({
          username:
            this.config.getOrThrow<string>(
              'SUPERSET_SERVICE_USERNAME',
            ),
          password:
            this.config.getOrThrow<string>(
              'SUPERSET_SERVICE_PASSWORD',
            ),
          provider: 'db',
          refresh: false,
        }),
      },
    );

    if (!response.ok) {
      const responseBody =
        await response.text();

      this.logger.error(
        [
          'Superset service login failed.',
          `Status: ${response.status}`,
          `Body: ${responseBody}`,
        ].join(' '),
      );

      throw new BadGatewayException(
        'Unable to authenticate with Superset',
      );
    }

    const result =
      (await response.json()) as
        SupersetLoginResponse;

    if (!result.access_token) {
      throw new BadGatewayException(
        'Superset returned an empty access token',
      );
    }

    return result.access_token;
  }

  private buildOrganizationRlsClause(
    organizationId: string,
  ): string {
    /*
     * organizationId originates from the authenticated application user,
     * not from the request body.
     *
     * Escaping protects the SQL literal, but a numeric internal tenant ID
     * is preferable where possible.
     */
    const escapedOrganizationId =
      organizationId.replaceAll(
        "'",
        "''",
      );

    return (
      `organization_id = ` +
      `'${escapedOrganizationId}'`
    );
  }

  private getBaseUrl(): string {
    return this.config
      .getOrThrow<string>(
        'SUPERSET_INTERNAL_URL',
      )
      .replace(/\/+$/, '');
  }
}
```

Superset's REST API exposes a guest-token endpoint and dashboard APIs. The guest token should identify the permitted dashboard resource and may carry RLS rules for tenant isolation.

### 9.18 NestJS controller — `superset.controller.ts`

```ts
import {
  Body,
  Controller,
  Get,
  Post,
  Req,
  UseGuards,
} from '@nestjs/common';

import type {
  Request,
} from 'express';

import {
  SupersetApiService,
} from './superset-api.service';

import {
  SupersetDashboardRegistryService,
} from './superset-dashboard-registry.service';

import {
  SupersetGuestTokenDto,
} from './superset-guest-token.dto';

interface ApplicationUser {
  id: string;
  email: string;
  firstName?: string;
  lastName?: string;
  organizationId: string;
}

interface AuthenticatedRequest extends Request {
  user: ApplicationUser;
}

@Controller('superset')
export class SupersetController {
  constructor(
    private readonly supersetApi:
      SupersetApiService,
    private readonly dashboardRegistry:
      SupersetDashboardRegistryService,
  ) {}

  /**
   * The Angular application can use this endpoint to discover the
   * organization-specific initial embedded-configuration UUID.
   */
  @Get('configuration')
  // @UseGuards(YourExistingAuthenticationGuard)
  getConfiguration(
    @Req() request:
      AuthenticatedRequest,
  ) {
    const organizationId =
      request.user.organizationId;

    return {
      initialEmbeddedId:
        this.dashboardRegistry
          .getInitialEmbeddedId(
            organizationId,
          ),
    };
  }

  @Post('guest-token')
  // @UseGuards(YourExistingAuthenticationGuard)
  async createGuestToken(
    @Req() request:
      AuthenticatedRequest,
    @Body() dto:
      SupersetGuestTokenDto,
  ) {
    const user = request.user;

    /*
     * The browser's UUID is treated only as a request. The registry decides
     * whether that UUID belongs to the authenticated organization.
     */
    const dashboardId =
      this.dashboardRegistry
        .resolveAllowedDashboard(
          user.organizationId,
          dto.dashboardId,
        );

    const token =
      await this.supersetApi
        .createGuestToken({
          dashboardId,
          username: user.email,
          firstName:
            user.firstName ?? 'Embedded',
          lastName:
            user.lastName ?? 'User',
          organizationId:
            user.organizationId,
        });

    return {
      token,
      dashboardId,
    };
  }
}
```

Use your existing authentication guard on both endpoints. The guest-token endpoint must not trust a tenant or organization identifier supplied by Angular.

### 9.24 Important behavior boundaries

This preserves:
- the iframe DOM element;
- iframe `contentWindow`;
- iframe document;
- Superset JavaScript runtime;
- SDK MessageChannel;
- theme and embedding context.

It intentionally resets:
- `DashboardPage`;
- dashboard-local React state;
- chart components;
- dashboard metadata;
- dashboard-specific filter state.

The dashboard itself must reload its metadata and charts. "No iframe reload" cannot mean "no data loading"; it means the browser does not navigate or reconstruct the embedded Superset application.

The patch should be maintained as a downstream patch tied to the exact Superset release. Superset's public embedding workflow remains based on the Embedded SDK, while the `DashboardPage` and embedded application source modified here are internal frontend implementation details.
